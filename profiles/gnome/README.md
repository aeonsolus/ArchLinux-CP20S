# GNOME tablet profile

The intended profile is GNOME Shell 51 on Wayland with TouchUp gestures and TouchBoard as the default docked touch keyboard. This is a release target, not a claim that the current repository installs or validates the profile.

See [the desktop requirements](../../docs/DESKTOP.md). Extension versions must be pinned and checked against the selected GNOME package snapshot. TouchBoard integration and text entry in GNOME, Chrome, and Electron are release gates; Squeekboard is not an approved substitute.
