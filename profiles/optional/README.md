# Optional packs

Optional packs are installed separately from the base image. A pack must have
an explicit package list, upstream links, license/redistribution notes, and a
check that it does not enable services or add desktop entries without telling
the user.

Planned packs: browser/media, appearance/wallpapers, developer tools, and
security tools. Kali packages are not copied wholesale; only individually
reviewed tools that build and run on AArch64 Arch may be listed. Proprietary
fonts and vendor applications are user-provided where their licenses require
it. No pack has been declared release-ready yet.
